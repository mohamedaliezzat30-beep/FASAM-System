# Fire and Security Alarm Monitoring System (FASAM)

## Overview

The Fire and Security Alarm Monitoring System (FASAM) is a safety-critical software system designed to monitor, manage, and respond to fire and security incidents within a large multi-zone building environment.

The system integrates fire detection, security monitoring, emergency response automation, occupancy verification, evacuation management, and operator control functions.

---

## Features

- Fire alarm detection and confirmation
- Security alarm monitoring
- Automatic emergency notification
- Evacuation alert activation
- Exit route indicator control
- Sprinkler activation management
- Electrical equipment shutdown
- Automatic zone isolation
- Incident logging and audit tracking
- Operator dashboard monitoring
