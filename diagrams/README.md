# UML Diagrams

This folder contains all UML use case diagrams created for the FASAM system using ArgoUML.

Included diagrams:
- Fire Services Use Case Diagram
- Security Services Use Case Diagram
- System Operator – Manual Diagram
- System Response – Automatic Diagram
- Consolidated Use Case Diagram

These diagrams model system interactions, emergency responses, and operator behaviour within the safety-critical environment.
